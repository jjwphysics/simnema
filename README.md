# Simnema

수능과 모의평가에 출제된 현대소설의 장면을 초단편 영화로 만나는
정적 웹 상영관입니다.

## 미리보기

`Simnema 미리보기.cmd`를 더블클릭합니다.

별도의 Node.js, 개발 서버, 패키지 설치가 필요하지 않습니다. 실행할
때마다 작품 폴더의 영상·본문·정보를 다시 읽은 뒤 기본 브라우저에서
사이트를 엽니다. `index.html`을 직접 열어도 현재 저장된 내용으로
사이트를 볼 수 있습니다.

## 작품 폴더

폴더명은 `작가명 - 작품명 (출제학년도-월)` 형식을 사용합니다.

각 폴더에는 다음 파일을 둘 수 있습니다.

- MP4 영상 1개
- `본문.txt`
- `정보.txt`

## GitHub Pages

저장소의 `main` 브랜치에 전체 프로젝트를 올린 다음
**Settings → Pages → Source → GitHub Actions**를 선택합니다.

이후 새 작품을 올리거나 내용을 수정해 `main`에 반영하면 포함된
워크플로가 작품 목록을 다시 만들고 사이트를 자동으로 게시합니다.
